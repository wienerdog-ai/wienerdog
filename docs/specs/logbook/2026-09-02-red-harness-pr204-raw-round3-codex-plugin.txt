- [P2] Detect declarations added before SNAPSHOT — /Users/gyulafeher/Documents/Claude_Projects/wienerdog-wt/criterion-red-harness/scripts/red-proofs.js:372-374

The new declaration is copied and manifest-verified but omitted from `all` and the roll-up, allowing `PROVEN` while the snapshotted declaration set contains unrun evidence, contrary to the concurrent-edit guarantee in [Table B row 2](docs/specs/WP-criterion-red-harness.md#L287). - [P2] Keep the unit suite green on unsupported lane hosts — /Users/gyulafeher/Documents/Claude_Projects/wienerdog-wt/criterion-red-harness/tests/unit/red-proofs.test.js:997-997

Thus `npm test` fails wholesale in Windows development or root-based containers, rather than merely confirming that the lane refuses execution, conflicting with [criterion 13](docs/specs/WP-criterion-red-harness.md#L894). Skip permission-dependent cases or inject a supported host for functional runner tests while retaining dedicated refusal tests.
