
**I stopped guessing at TAP shapes and captured them.** My first synthetic matrix was wrong twice — I put the parent before its children, and I indented the inner plan — so I captured the real streams instead. Node 25.9.0's unmatched-pattern output is `1..0` at **column 0**, then a childless `ok` named for the file, then `1..1`; a file registering no tests emits the same thing *without* the leading `1..0`. That is exactly the discrimination the code makes, and against real streams it is right:

```
unmatched pattern          identities=[]                          ranNodes=0
file registering NO tests  identities=[tests/suite-empty.js]      ranNodes=1
normal suite               identities=[greeting | arity]          ranNodes=2
namesake suite             identities=[tests/… | suite-… | …]     ranNodes=3
```
