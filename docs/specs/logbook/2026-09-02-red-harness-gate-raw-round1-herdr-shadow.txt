FINDING 3
Affected file: docs/specs/WP-criterion-red-harness.md
Lines: 176-189
Confidence: 0.98
Materiality: A
Body: Name-set equality plus an arbitrary diagnostic substring does not prove a named assertion failed. `signal` is not required to be non-empty, so `""` matches every diagnostic. A mutation causing a lazy-loaded module to throw `SyntaxError`, or a `beforeEach` hook to fail, can therefore produce the expected test name without executing its assertion. TAP also permits skipped/TODO records and duplicate test names; reducing names to a set loses identity and multiplicity. These runs can satisfy the written RED rule while proving only that test infrastructure broke.
Recommendation: Require non-empty `test` and `signal`; exactly one baseline `type: test` pass per declared identity; reject skipped, TODO, cancelled, suite, hook and file-level failures; and require an assertion failure diagnostic such as `failureType: testCodeFailure` plus `ERR_ASSERTION`. Reject duplicate observed or declared identities.

FINDING 4
Affected file: docs/adr/0042-machine-run-red-proofs.md
Lines: 47-53
Confidence: 0.96
Materiality: B
Body: The ADR says a criterion is PROVEN only when all its proofs pass, but the spec allows `--proof` to select one proof and then rolls results up per criterion. If criterion C has proofs A and B, selecting only A can exit 0 under V4 and be rolled up as criterion C PROVEN without running B. The standing footer also says “each declared mutation,” not “each selected mutation,” overstating a filtered run.
Recommendation: Filtered runs may report selected proofs PROVEN but must report criterion roll-ups as PARTIAL/FILTERED. Emit criterion PROVEN only when every declaration for that `(wp, criterion)` was selected, ran, and passed; make the footer describe selected evidence.

FINDING 5

Lines: 171-188
Confidence: 0.95
Materiality: B
Body: APPLY does not define occurrence or transformation semantics. For `find: "aa"` in `"aaa"`, overlapping counting yields two occurrences while ordinary replacement changes one. The stated postconditions—marker present and digest changed—still pass.
