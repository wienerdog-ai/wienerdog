- [high] [A] Angle-bracket counting can select a comment as the recipient (docs/specs/WP-audit-d-code-derived-recipients.md:330-331)
  Table B selects old@example.net from 'alice@example.org (backup <old@example.net>)', although the mailbox is alice@example.org. The Python email parser reports that source header as valid with no defects. It also accepts 'alice@example.org, Bob <bob@example.net>' as one candidate, silently discarding the first mailbox, and refuses the valid single-mailbox header '"Team <east>" <alice@example.org>'. Thus an implementation satisfying the literal table and criterion 3 can address the wrong mailbox. Counting bracket groups does not establish exactly one mailbox.
  Recommendation: Specify extraction that accounts for quoted display names, comments and the entire address list. Reject unsupported or ambiguous syntax instead of extracting substrings from it. Add these three cases to AUD-D2/AUD-D3.
