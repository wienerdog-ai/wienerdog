## Findings

**1. [contract] `src/core/dream/promote.js:619-641` — the public `@returns` JSDoc declares the retired, pre-reconciliation return shape. The implementation is correct; only its type surface is stale.**

The code builds the right thing — `promote.js:1002-1005` annotates and `:1017`, `:1037-1041`, `:1047-1053` construct:
- `redacted[]` = `{rel, bytes, redaction: RedactionAccounting, preserved: PreservedCopy[]}`
- `refused[]` = `{rel, reason, preserved: PreservedCopy[]}`

But the `@returns` block still reads:

```js
 * @returns {{promoted:Array&lt;{rel:string, bytes:Buffer}&gt;,
 *            redacted:Array&lt;{rel:string, bytes:Buffer,
 *                            lines:number, labels:string, artifact:string}&gt;,
 *            refused:Array&lt;{rel:string, reason:string}&gt;,
 *            secretDisposition:{withheld:number, redactions:number}}}
```

Three concrete defects:
- **`:621`** declares the flat `lines` / `labels` / `artifact` triple. Table Q row **Q10** rules the accounting is ONE field named `redaction` ("WHY ONE FIELD AND NOT TWO"), and row **Q8** says of the flat `artifact` field: "**That field no longer exists.**" It also omits `preserved` entirely.
- **`:622`** declares `refused:Array&lt;{rel:string, reason:string}&gt;`, contradicting the spec's `### Exact contracts` (`refused:Array&lt;{rel:string, reason:string, preserved:Array&lt;PreservedCopy&gt;}&gt;`), Table S row **S3** ("`refused[]` is `{rel, reason, preserved}`") and Table Q row **Q8** (`preserved` REQUIRED, possibly empty).
- **`:633`** prose repeats it: "`refused[]` is `{rel, reason}` and carries NO bytes". **`:637-641`** prose attributes the accounting to "Table Q row Q1" (Q10 owns it) and names "the artifact name the gate RETURNED" as a field of `redacted[]`.

The correctly-declared typedefs at `:539-558` are used at `:1002` and `:1004` but never reached the public signature — commit `9993cc5` ("carry the preserved copy typed, not in prose") changed the shape and the `@returns` was not swept with it.

Why contract-band under the obligation test: CLAUDE.md forbids TypeScript in `src/`, so this JSDoc **is** the module's type contract, and two other packages must agree with it — Table S row **S6** names `WP-dream-promote-in-workspace`'s G8 (dream commit) and G10 (registry) as the consumers, and `WP-dream-promote-report` extends this exact union. A consumer coding against `:619-623` would look for `entry.artifact` and `entry.lines` (gone) and would not know `refused[]` carries `preserved` — which is precisely the data-loss route row Q8 exists to close.

This is my round-2 finding **N3** ("stale `decisions` JSDoc — this project's only type surface") recurring on the module's public return. It also means the spec's **Mirrored Surface Checklist** item "`### Exact contracts`' signature and its return shape" (`docs/specs/WP-dream-promote-module.md:683`) was not actually walked — every box in that checklist is still unchecked.

**Fix**: replace `:619-623` with the spec's `### Exact contracts` `@returns` verbatim (using the `RedactionAccounting` and `PreservedCopy` typedefs already declared at `:555`/`:548`); correct `:633` to `{rel, reason, preserved}`; rewrite `:637-641` to cite **Q10** for the `redaction` field and drop the `artifact` clause.
