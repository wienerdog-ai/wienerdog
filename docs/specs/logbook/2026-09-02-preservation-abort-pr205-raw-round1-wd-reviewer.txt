### Findings

**1. `[contract]` Band B — a registered mirror named in the spec's own checklist was left byte-unchanged.**
`/Users/gyulafeher/Documents/Claude_Projects/wienerdog-wt/preservation-abort-widening/src/core/dream/validate.js:1046-1047`

```js
   * @throws {WienerdogError} the preservation-failure abort — the one case in
   *   which no durable artefact holds the bytes being judged
```

This is identical to `origin/main`, yet the Mirrored Surface Checklist lists it first under "Mirrors outside this document (all inside the Deliverables boundary) — **the gate's `@throws` JSDoc** and `quarantinePreserve`'s `@returns` in `validate.js`". The `@returns` mirror was updated; this one was not. It is now wrong in three ways:

- **It declares one throw where there are now two structurally different ones.** Table D row D3 propagates out of `quarantinePreserve` and straight out of `secret()`. I confirmed it escapes the gate: driving a hard secret with a corrupted quarantine write and `rmSync` throwing yields `WienerdogError: quarantinePreserve: could not remove "…/quarantine/2026-09-02-n.md" after a preservation failure: EPERM`. That is a cleanup failure, not "no artefact holds the bytes being judged", and a caller reading this contract does not learn it exists.
- **"the one case"** is the narrowing the WP exists to retire; the trigger is now a class (Table P rows P0–P3).
- **"durable"** over-claims. B3b's own new clause spells out that the durable conjunct is deferred to `WP-quarantine-preserve-durability` and that P0b establishes byte-identity only. A gate contract saying the abort fires when no *durable* artefact holds the bytes asserts more than the code enforces.

*Disposition: **fix.*** One JSDoc block in a Deliverables-listed file; comment-only, no behaviour change, no new test. Suggested shape: state the class (Table P row P0 — no verified artifact holds the judged bytes) and add a second `@throws` line for Table D row D3, and drop or qualify "durable" the way `quarantinePreserve`'s amended `@returns` already does.
