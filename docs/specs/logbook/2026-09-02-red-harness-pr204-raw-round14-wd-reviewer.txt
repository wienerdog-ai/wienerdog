```
clean TMPDIR, nothing above it        -> RUN: PROVEN
plant <ancestor>/node_modules two up  -> exit 1, UNSUPPORTED, 0 proofs, ends with REACH
                                          names the exact offending directory
remove it again                       -> RUN: PROVEN
```

Three states, so the guard is non-vacuous in both directions. The implementation is careful in ways worth naming: it realpaths first, uses `lstat` rather than `existsSync` (a symlinked *or dangling* `node_modules` still shadows resolution, so presence is the fact), and bounds the walk at 256 levels. `R14-a` (bypass) kills 2; `R14-b` (check only the sandbox directory, no walk) also kills 2 — so the *walk*, not just the check, is pinned.

**I verified the stated residue rather than accepting it.** Under an injected HOME, `module.globalPaths` is:

```
<HOME>/.node_modules      ← follows the injected HOME
<HOME>/.node_libraries    ← follows the injected HOME
/opt/homebrew/Cellar/node/25.9.0_2/lib/node   ← the Node installation
```

Two of the three track HOME, which the runner redirects into the phase copy, so they land inside it and are not shared across phases. The third is the Node installation's own `lib/node` — correctly named as the installation's trust boundary rather than pretended away. The REACH footer states exactly this.

**The false-positive question the coordinator raised — I tested it, and it is not a false positive.** I built the realistic case (`TMPDIR=$HOME/tmp` with a stray `$HOME/node_modules`) and then checked whether the refusal is *earned*:

```
bare import from a sandbox-shaped dir -> RESOLVED-FROM-HOME
```

Node really does resolve a bare import from a sandbox-shaped directory through that tree. So on such a host the isolation genuinely would be broken, and refusing is the right call — a developer with that layout has a real shared, writable dependency source above every phase copy. The message is actionable on all three counts a refusal needs: it names the offending directory by full path, names the sandbox it sits above, explains the mechanism ("Node walks EVERY ancestor … with no environment variable involved"), and gives two concrete remedies ("Point TMPDIR at a directory with no node_modules above it, or remove that tree").
